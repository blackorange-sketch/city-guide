# Путівник (City Guide)

Android-застосунок, який для будь-якого міста будує пішохідний маршрут по найцікавіших місцях. Це пробний прототип (MVP) на безкоштовних відкритих даних, без API-ключів.

## Як це працює

1. **Пошук міста:** підказки назв під час введення (Photon), пошук за назвою (Nominatim) або за поточною геолокацією (кнопка 📍, без Google Play Services).
2. **Місця:** Overpass API бере з OSM об'єкти (`tourism`, `historic`, храми) **лише з тегом `wikidata`**: так відсіюється дрібниця.
3. **Значущість:** Wikidata дає назву, короткий опис і кількість мовних версій у Вікіпедії. Чим більше версій, тим відоміше місце.
4. **Підбір:** кількість зупинок залежить від тривалості прогулянки (~30 хв на зупинку), можна фільтрувати за категоріями.
5. **Порядок обходу:** найближчий сусід + покращення 2-opt.
6. **Маршрут:** пішохідний маршрут по дорогах від `routing.openstreetmap.de` (OSRM).
7. **Карта:** MapLibre Native + векторні тайли OpenFreeMap. Усі знайдені місця нанесені кольоровими маркерами за категоріями, при наближенні з'являються підписи, тап по маркеру відкриває картку місця. Overpass має кілька резервних дзеркал.
8. **Фото й описи:** при виборі місця підтягується стаття Вікіпедії (фото + розгорнутий опис).
9. **Редагування маршруту:** видалення зупинок, переміщення вгору/вниз, додавання місця з карти (вставляється туди, де маршрут подовжується найменше), автоматичне впорядкування, перерахунок шляху після кожної зміни.
10. **Заклади харчування:** кафе, ресторани, фастфуд, бари з OpenStreetMap; кнопка «Обід поруч» додає заклад біля середини маршруту.
11. **Розширений пошук:** радіус 1–10 км та режим, що додає іменовані атракції, замки й пам'ятники без запису у Wikidata.
12. **Навігація всередині застосунку:** кнопка «▶ Навігація» вмикає режим із GPS. На карті видно ваше положення, пройдений відрізок (сірий), наступну зупинку (помаранчева) і позначки найближчих поворотів. Зверху банер із відстанню до маневру й підказкою українською, знизу відстань до зупинки та залишок шляху. Прибуття на зупинку визначається автоматично (35 м), є пропуск зупинки, голосові підказки (потрібен український голос у системному синтезаторі мовлення) та автоматичний перерахунок, якщо ви зійшли з маршруту. Екран не гасне. Окремо лишилась кнопка відкриття маршруту в Google Maps.

## Стек

Kotlin, Jetpack Compose (Material 3), MapLibre Android SDK, OkHttp, kotlinx.serialization, coroutines. `minSdk 26`.

## Збірка

Локально потрібен Android Studio (Ladybug або новіша) і JDK 17: відкрийте папку проєкту й запустіть `app`.

Gradle wrapper у репозиторії не додано. Android Studio запропонує його створити, або виконайте `gradle wrapper --gradle-version 8.10.2`.

**GitHub Actions** при кожному push у `main` збирає підписаний APK і публікує його в **Releases** (остання версія позначена Latest). Завантажуйте `CityGuide.apk` зі сторінки релізів.

**Оновлення поверх:** усі збірки підписані одним ключем (`keystore/release.jks`), а `versionCode` дорівнює номеру запуску, тому нова версія встановлюється поверх старої без видалення.

> Ключ лежить у відкритому репозиторії, це прийнятно лише для прототипу. Перед публічним релізом перенесіть його в GitHub Secrets і згенеруйте новий (старі збірки тоді доведеться перевстановити).

## Обмеження прототипу

- Публічні сервіси (Nominatim, Overpass, routing.openstreetmap.de) мають ліміти чесного використання: для реальних користувачів потрібен власний бекенд із кешем.
- Дані OSM/Wikidata різної повноти: у великих містах місць багато, у малих мало.
- У закладів харчування немає рейтингів і меню: OSM їх не містить (є кухня, години, сайт, якщо заповнені). Рейтинги потребують Google Places або Foursquare з API-ключем. Заклади ранжуються за повнотою даних.
- Навігація працює лише поки застосунок відкритий (фонового сервісу немає), потрібен інтернет для карти й перерахунку.
- Немає офлайн-режиму.
